# Cloud

Memori Cloud is the fully managed deployment of Memori. Connecting your agents requires an API key and Memori will handle all the infrastructure and scaling.

## What Cloud Includes

- Agent memory capture and recall through a single API key
- Memori-managed infrastructure across AWS regions
- Dashboard access for inspecting and managing memories
- Automatic upgrades and platform maintenance
- Standard support

## When Cloud Is the Right Choice

Cloud is suitable for teams that:

- Want to integrate Memori quickly without infrastructure work
- Prefer a usage based pricing model over a deployment engagement

## When to Move to Enterprise

If your requirements include any of the following, Memori Enterprise is the right deployment:

- Memory data must remain inside your cloud account or on-premises environment
- Regulated workloads: HIPAA, GDPR, SOC 2, or similar compliance requirements
- Dedicated infrastructure: no shared compute or storage
- Custom SLA with defined uptime and response commitments
- Air-gapped or restricted-network environments

See [Enterprise Grade](/docs/memori-enterprise/concepts/enterprise-grade) for a full comparison.

## Getting Started with Cloud

Sign up at [memorilabs.ai](https://memorilabs.ai) to create an account and receive your API key. Documentation for Cloud integrations is available in the [Memori Cloud docs](/docs/memori-cloud).
