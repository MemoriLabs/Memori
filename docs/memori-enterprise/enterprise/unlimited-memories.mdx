# Production Plans

Memori Enterprise includes unlimited memory creation and recall on every production plan. There is no per-memory fee, no per-recall fee, and no usage cap on memory operations.

## What Is Included

| Operation | Included |
| --------- | -------- |
| Memory capture | Unlimited |
| Memory recall | Unlimited |
| Pool reads and writes | Unlimited |
| Memory storage | Within your deployment boundary |

## Why It Matters at Scale

Agent operations are memory-intensive by design. Every completed session generates capture events; every incoming prompt triggers recall across entity memory and any attached pools. At production scale, with dozens or hundreds of agents running continuously, per-operation pricing creates two problems: unpredictable cost and misaligned incentives.

When memory operations carry a per-unit cost, teams optimize for fewer captures and fewer recalls. That optimization directly reduces agent quality: less captured means weaker memory, and less recalled means agents operating with less context. Unlimited memory operations remove that tension. Agents can run at full fidelity without cost arithmetic shaping the implementation.

## How Enterprise Pricing Works

Enterprise pricing is based on your deployment model, scale, and contract terms, not on memory counts.

Outcome-based pricing, where pricing is tied to measurable agent performance improvements, is available for qualifying deployments. Contact [support@memorilabs.ai](mailto:support@memorilabs.ai) to start a conversation.
