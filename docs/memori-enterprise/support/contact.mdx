# Contact Enterprise

## Sales and New Deployments

To start an Enterprise engagement — new deployment, scoping conversation, or pricing inquiry:

- **Web:** [memorilabs.ai/contact](https://memorilabs.ai/contact)
- **Email:** [enterprise@memorilabs.ai](mailto:enterprise@memorilabs.ai)

A solutions engineer will respond to schedule a scoping call. Come prepared with your:

- Deployment preference (BYOC or on-premises)
- Cloud provider and region (for BYOC)
- Database backend (MongoDB, PostgreSQL, etc.)
- Approximate scale (number of agents, memory volume)
- Compliance requirements (SOC 2, HIPAA, GDPR, other)

## Existing Enterprise Customers

If you are an existing Enterprise customer, contact your dedicated solutions engineer directly. For urgent production issues, use the support channel specified in your SLA documentation.

**General support:** [support@memorilabs.ai](mailto:support@memorilabs.ai)

## Security Disclosures

To report a security vulnerability, email [security@memorilabs.ai](mailto:security@memorilabs.ai). Do not file security issues in public GitHub issues. We respond to all security disclosures within one business day.

## Documentation and Compliance Requests

To request SOC 2 Type II reports, BAA, DPA, or other compliance documentation:

**Email:** [enterprise@memorilabs.ai](mailto:enterprise@memorilabs.ai)

Documentation is provided under NDA to qualified enterprise customers and prospects.
