# Getting started with Memori Enterprise

Memori Enterprise is deployed directly into your infrastructure. This page covers what the onboarding process looks like and what to prepare before your first deployment.

## What to prepare

Before your deployment begins, gather the following:

- **Infrastructure access**, so Memori can be deployed into your VPC or on-prem environment.
- **Harness user count**, including any additional integrations that will write to Memori.
- **Data residency requirements**, covering region constraints for memory storage and processing.

## First steps after access

Once your deployment is live:

1. **Log in to your Enterprise dashboard**: Your organization owner receives an invite to the Memori Enterprise dashboard.
2. **Create your first memory pool**: Define a shared pool for your team's highest-priority project context. See [Memory pools](/docs/memori-enterprise/memory-pool/overview).
3. **Connect the harness**: Each user installs and configures the Memori plugin. See [Quickstart](/docs/memori-enterprise/getting-started/quickstart).
4. **Review the audit log**: Confirm memory reads and writes are being recorded correctly before rolling out to additional users.
