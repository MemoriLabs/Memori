# Memory Explorer

Memory Explorer is the visual interface for browsing, searching, and inspecting memories across your entire deployment. It gives your team direct visibility into what Claude Code knows, how memories were formed, and which facts are shaping responses.

## What it's for

Memory Explorer is where owners and admins verify that memories are accumulating correctly and investigate what Claude Code is drawing on before each response. It is also where incorrect or stale memories can be found and removed.

## Searching and browsing

Search across all memories by entity, pool, keyword, or tag. Results show the memory content, its signal type, horizon, and when it was created and last recalled.

Filter by:

- **Entity**: view all memories for a specific user
- **Pool**: inspect the contents of a memory pool
- **Memory type**: Domain (concepts), Entity (people or things), or Process (task outputs)
- **Signal**: Constraint, Fact, Failure, Goal, Outcome, Preference, Strategy, or Workflow
- **Horizon**: Decaying (loses relevance over time), Standing (persists until removed), or Volatile (short-lived, tied to current session)
- **Date range**: memories created or updated within a window
- **Tag**: memories labeled with a specific tag

## Inspecting individual memories

Click any memory to see its full detail: content, source session and turn, augmentation confidence score, recall count, last recalled timestamp, and linked memories in the knowledge graph.

## Edit and delete

Owners can edit memory content or permanently delete individual memories directly from the Explorer. Admins can remove memories from pools but cannot permanently delete them. All edits and deletions are recorded in the audit log with the acting user and timestamp.

## Knowledge graph view

Switch to **Graph View** to see memories as a network of entities, facts, and relationships. Graph View is useful for understanding why Claude Code responded a certain way, identifying contradictory or stale facts before they affect future responses, and visualizing which users or topics have the densest memory coverage.
