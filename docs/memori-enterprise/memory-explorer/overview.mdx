# Memory Explorer

Memory Explorer is the visual interface for browsing, searching, and inspecting memories across your entire deployment. It gives your team direct visibility into what the harness knows, how memories were formed, and which facts are shaping responses.

## What it's for

Memory Explorer is where owners and admins verify that memories are accumulating correctly and investigate what the harness is drawing on before each response. It is also where incorrect or stale memories can be found and removed.

## Searching and browsing

Search across all memories by entity, pool, keyword, or tag. Results show the memory content, its signal type, horizon, and when it was created and last recalled.

Filter by entity, pool, memory type (Domain, Entity, or Process), signal type (Constraint, Fact, Failure, Goal, Outcome, Preference, Strategy, or Workflow), horizon (Decaying, Standing, or Volatile), date range, or tag.

## Inspecting individual memories

Click any memory to see its full detail: content, source session and turn, augmentation confidence score, recall count, last recalled timestamp, and linked memories in the knowledge graph.

## Edit and delete

Owners can edit memory content or permanently delete individual memories directly from the Explorer. Admins can remove memories from pools but cannot permanently delete them. All edits and deletions are recorded in the audit log with the acting user and timestamp.

---

## Using Memory Explorer

### 1. Search for memories

Open Memory Explorer and use the search bar or apply filters to locate memories by entity, pool, keyword, tag, signal type, or date range.

### 2. Inspect a memory

Select any memory from the results list to open its detail view.

- Review the memory content and its signal type
- Check the source session and turn it was extracted from
- Review the recall count to see how often this memory is being used

### 3. Remove or delete

Choose a removal action based on your role and intent.

- **Remove from pool**: removes the memory from this pool only; the memory remains in the memory bank
- **Delete permanently**: removes the memory from the memory bank and all pools (owners only)
