# Async Gateway

Memory capture and extraction in Memori are asynchronous. When an agent session ends, the conversation is transmitted to the Memori server, but the memories extracted from it are not immediately queryable. Understanding this pipeline helps you set correct expectations for the dashboard and for recall timing in subsequent sessions.

## The Async Pipeline

```
Agent session ends
      │
      ▼
Stop hook fires → transmits completed turn to Memori server
      │
      ▼
Turn stored (immediately available for audit)
      │
      ▼
Augmentation worker picks up the turn (background)
      │
      ▼
Advanced Augmentation extracts memory signals
      │
      ▼
Memories indexed and available for recall
```

The transmission step is synchronous within the hook: the hook completes after the turn is accepted by the server. The extraction step runs in a background worker and completes independently.

## Timing Expectations

- **Immediately after a session**: the turn is stored; memories are not yet available.
- **After extraction completes**: memories appear in the dashboard and are included in subsequent recall queries.
- **Extraction duration**: typically a few seconds to a few minutes depending on turn length and server load.

If you check the dashboard immediately after a session and see no new memories, wait a moment and refresh. Empty recall on the very next session after initial setup is expected; memories from the first session will appear once extraction finishes.

## Interrupted Sessions

A session ended with `ESC` or terminated before the Stop hook fires is not transmitted. No turn is stored and no memories are extracted. Only completed turns reach the Memori server.

## Pool Writes

Pool memory writes follow the same async pipeline. An agent writing to a pool submits the content for extraction; other agents with pool access will see the resulting memories after extraction completes, not at the moment of submission.

## Hook Timeout Considerations

The Stop hook budget must cover both the turn transmission and any augmentation request made during the hook. Augmentation is the slower of the two steps. If the hook timeout is shorter than the observed augmentation latency, the hook may time out after storing the turn but before extraction completes. Failures at this stage are written to the hook's stderr and visible with `claude --debug-file`.
