# Enterprise Grade

Memori Enterprise is built for organizations that cannot accept the tradeoffs of shared infrastructure. The differences from the managed cloud offering are architectural, not just contractual.

## No Multi-Tenancy

In Memori Cloud, compute and storage are shared across all customers. In Memori Enterprise, your deployment runs on infrastructure dedicated to your organization alone. No shared compute, no shared storage, no shared network paths. Your memory data is not co-located with any other customer's data.

## Full Data Sovereignty

All memory capture, augmentation, and recall happen within the boundary you control. Memori does not copy, cache, or index data outside that boundary. You choose where your deployment runs, and data does not leave that environment for any reason, including telemetry, which is fully opt-out.

## Compliance Controls Built In

Enterprise compliance requirements (data residency, audit logging, access governance, and retention) are built into the architecture:

- SOC 2 Type II, HIPAA, GDPR, and ISO 27001 controls are structural, not procedural
- Immutable audit logs for every memory operation
- Role and relationship-based access control (ReBAC) with SSO integration
- TTL-based retention and on-demand erasure for GDPR right-to-erasure requests

See [Compliance](/docs/memori-enterprise/security/compliance) for certification details and documentation availability.

## Custom SLA

Every Memori Enterprise deployment is covered by a custom SLA with defined uptime commitments, response windows, and escalation paths. SLA terms are set during the scoping process and defined in your contract.

## Dedicated Support

Every Enterprise deployment includes dedicated support. We work with your team through architecture review, deployment, validation, and ongoing operations. We do not hand off after go-live.

## Unlimited Memory Operations

Production plans include unlimited memory capture and recall with no per-operation fees. See [Production Plans](/docs/memori-enterprise/enterprise/unlimited-memories) for pricing structure.

## When to Choose Enterprise

| Requirement | Memori Cloud | Memori Enterprise |
| ----------- | :----------: | :---------------: |
| No data outside your boundary | No | Yes |
| Dedicated infrastructure | No | Yes |
| Regulated workload (HIPAA, etc.) | No | Yes |
| Custom SLA | No | Yes |
| Air-gapped deployment | No | Yes |
| Simple API key integration | Yes | Yes |
| Unlimited memories | No | Yes |
