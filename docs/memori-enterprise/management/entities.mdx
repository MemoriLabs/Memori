# Entities

An entity is the person, user, or subject that a memory belongs to. Every memory in Memori is associated with an entity: the facts, preferences, and goals stored in Memori describe a specific entity's state and history.

## Entity IDs

Each entity is identified by an entity ID: a lowercase string you assign when configuring the agent. Entity IDs can be any consistent identifier that maps to a person or subject in your system, such as a user ID, email slug, or username.

```
jane-doe
user_8472
support-case-19043
```

The entity ID is the key that links an agent session to its memory space. An agent configured with `entity_id: jane-doe` reads from and writes to Jane Doe's memory, and no other entity's memory is accessible to that agent unless pool access has been granted.

## Consistency Across Clients

If multiple agents or integrations write to the same entity, use the same entity ID in every client. Memori accumulates memories across all sessions for a given entity ID, so a mismatched ID creates a separate memory space rather than contributing to the existing one.

If memory recall looks incomplete or the dashboard shows fewer memories than expected, verify that all clients are configured with the same entity ID.

## Entity Management

Owners and admins can view all entities in the organization from the Memori Enterprise dashboard. From the entity view, you can:

- Browse all memories attributed to an entity
- Delete individual memories
- Delete all memories for an entity (see [Remove Memories](/docs/memori-enterprise/management/remove-memories))

## Entity Deletion

To delete all memories associated with an entity, including facts, session records, and knowledge graph nodes, use the SDK:

```python
from memori import Memori

mem = Memori()
mem.entity.delete(entity_id="user_123")
```

This is the correct path for responding to user deletion requests under GDPR and similar data protection regulations. The deletion is permanent and recorded in the audit log.
