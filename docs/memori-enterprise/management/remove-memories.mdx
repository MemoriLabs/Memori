# Memory Removal

Memori provides several paths for removing memories, each with different scope and permission requirements. Understanding the difference between removing a memory from a pool and permanently deleting it from the memory bank is important before performing any removal.

## What removal means

<Properties>
  <Property name="Remove from pool">
    Removes the memory from that pool only. The memory remains in the memory bank and in any other pools it belongs to. Owners, admins, and users with the remove-memories pool permission can do this.
  </Property>
  <Property name="Permanently delete">
    Removes the memory from the memory bank and all pools it belongs to. This action is irreversible. Available to owners only.
  </Property>
  <Property name="Delete all entity memories">
    Removes all memories for a specific entity, including facts, session records, and knowledge graph nodes. Owners can do this via the SDK.
  </Property>
</Properties>

## Permissions

All removal and deletion actions are recorded in the immutable audit log with the acting user and timestamp. Owners see all removal options. Admins and users with remove-memories permission see pool removal only.

---

## Removing memories

### 1. Remove a memory from a pool

Open Memory Explorer, locate the memory, open its detail view, and select **Remove from pool**.

### 2. Permanently delete a memory

Follow the same path as pool removal, but select **Delete permanently**. This option is visible to owners only.

<Admonition type="warning">
  Permanent deletion removes the memory from the memory bank entirely. It is no longer accessible from any pool or through any recall query and cannot be undone.
</Admonition>

### 3. Delete all memories for an entity

To delete all memories associated with a specific entity, use the SDK:

```python
from memori import Memori

mem = Memori()
mem.entity.delete(entity_id="user_123")
```

<Admonition type="tip">
  This is the correct path for GDPR right-to-erasure requests. The deletion is permanent, covers all memory records for that entity ID, and is recorded in the audit log. See [Compliance](/docs/memori-enterprise/security/compliance) for more on data subject rights handling.
</Admonition>
