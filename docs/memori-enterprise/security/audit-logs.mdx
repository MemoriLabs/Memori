# Audit Logs

Memori Enterprise records every memory operation in an immutable audit log. Your security and compliance teams have a complete record of what happened, who did it, and when.

## What audit logs are for

The audit log supports security reviews, compliance evidence, and incident investigation. Because records are immutable and append-only, they cannot be modified or deleted by Memori administrators or your team.

## Audit log fields

Every memory operation generates an audit event with the following fields:

<Properties>
  <Property name="timestamp">UTC timestamp with millisecond precision.</Property>
  <Property name="operation">The operation type: `capture`, `recall`, `delete`, or `permission_change`.</Property>
  <Property name="entity_id">The entity whose memory was accessed.</Property>
  <Property name="process_id">The agent or application that performed the operation.</Property>
  <Property name="session_id">The session in which the operation occurred.</Property>
  <Property name="result">Whether the operation succeeded or was denied.</Property>
  <Property name="denial_reason">If denied: the access control rule that blocked the operation.</Property>
  <Property name="memory_ids">The specific memory records affected.</Property>
</Properties>

## Retention

Audit log retention is configurable independently of memory retention:

- **90-day default**: standard configuration
- **1-year HIPAA**: required for healthcare deployments
- **Indefinite**: no automatic expiry; archive to cold storage on a schedule

For on-premises deployments, Memori provides guidance on write-once storage configuration to satisfy specific compliance requirements.

## Observability and telemetry

Memori Enterprise exports metrics and traces into your existing observability stack via OpenTelemetry (OTLP) and Prometheus. For VPC deployments, native cloud monitoring integrations are available for the respective cloud provider.

Memori emits spans for every operation in the capture and recall paths, covering end-to-end latency, augmentation pipeline stages, and access control evaluation.
